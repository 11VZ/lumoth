Lumoth Uploader

Privacy Policy

Last updated November 9, 2026

Lumoth Uploader is a private program that publishes videos to the Lumoth channel on YouTube. Its only user is the owner of that channel. By signing in with Google to use it, the user agrees to this policy.

YouTube API Services

Lumoth Uploader uses YouTube API Services. Using it means you are also bound by the YouTube Terms of Service. Information handled through YouTube and Google is also covered by the Google Privacy Policy.

What it accesses

After the channel owner signs in with Google, Lumoth Uploader accesses this information for the Lumoth channel only:

  • The channel's name, upload list, linked status, and subscriber, view and video counts.
  • Each video's title, description, tags, category, privacy setting, processing status, region restrictions and statistics.
  • YouTube Analytics totals for each video: views, watch time, average view duration, average percentage viewed, likes, comments, shares and subscribers gained.
  • The Google sign-in tokens that allow this access.

It does not access information about individual viewers, and it does not download videos from YouTube.

How the information is used

  • To upload videos to the channel and confirm that each one arrived with the intended settings.
  • To give the channel owner a weekly report on how the videos are performing.

What is stored, and for how long

Everything is stored on the channel owner's own computer. There is no Lumoth server or database.

  • Sign-in tokens are kept until the owner disconnects the program.
  • A log of published videos keeps each video's ID and privacy setting. These are checked against YouTube every week, and a video deleted from YouTube is removed from the log's records.
  • Weekly reports contain YouTube's statistics and are deleted after 30 days.

Who it is shared with

Information is not sold, and it is not shared with advertisers. It goes to only these parties:

  • YouTube and Google, which receive the videos and details being uploaded.
  • Anthropic, whose AI assistant, Claude, the channel owner has approved as their agent to run this program and read its weekly reports. That processing is covered by Anthropic's Privacy Policy.

Ads and third-party content

Lumoth Uploader shows no ads and no third-party content.

Storage on devices and cookies

The program saves the tokens, log and reports described above as files on the channel owner's computer. It places no cookies or similar technology on anyone's device.

This website sets no cookies and uses no analytics. It is hosted on GitHub Pages, so GitHub receives visitors' IP addresses, and the YouTube logo on the home page loads from Google's servers.

Removing access and deleting data

The channel owner can remove Lumoth Uploader's access at any time on the Google security settings page.

Running the program's disconnect command revokes access at Google right away and deletes the stored tokens, reports, video IDs and anything learned from them.

If access is removed from Google's page instead, or the login can no longer be refreshed, the same stored data is deleted within 30 days. Requests to delete data are completed within 7 days. Deleting data here does not affect what YouTube itself stores.

Children

Lumoth Uploader is not directed at children, and videos it uploads are declared as not made for kids.

Changes to this policy

Any change is posted here with a new date. If data would be used in a way this policy does not cover, the channel owner must accept the new policy before that use begins.

Contact

Questions or complaints can be sent by opening an issue on the project's GitHub page.
